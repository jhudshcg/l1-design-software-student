In VS Code open Terminal → New Terminal. Check it is in your cloned repository folder. Replace the quoted details below with your own. Run each line once.

These settings apply to this repository. Close the terminal afterwards; use Source Control for the project.

Start B · Save a checkpoint

Saveupdates a file
Commitrecords a checkpoint
Backupa separate safe copy
  1. Save all edited files (File → Save All).
  2. Open Source Control on the left. Click each changed file to review it.
  3. Use the + beside your intended files to stage them. First checkpoint: include your project files and images.
  4. Write a message such as “Added starter project”, then select Commit.

New files may show U; edited tracked files show M. Make another checkpoint after research, design and a useful correction.

Check: Your committed files leave the Changes list. View Source Control Graph or the file Timeline to see the checkpoint.

Help: images and sources

Use your own images or a teacher-approved source. Check the image’s permission/credit requirements; a search result is not permission. Use a short name, such as fruit-pot.jpg. Keep the real extension. Do not just rename .webp to .jpg.

Keep one clear source reference per item. More than one item can share a source. Record another constraint too, such as privacy or accuracy.

Help: data types and image paths 
name: "Fruit pot",
price: 1.40,
image: "images/fruit-pot.jpg",
type: "snack",
description: "Fresh fruit pieces.",
healthpromo: true,
alergy_warning: []

Prices are numbers: no quotes or £. Use main, snack or drink in lower case. true/false have no quotes. Keep the starter’s spelling alergy_warning. Lists use square brackets; allergen words need quotes.
